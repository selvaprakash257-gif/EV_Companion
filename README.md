# EV Companion 🚗⚡

A Python-based EV Companion application developed as a learning project to explore software development for electric vehicles.

## 📌 About the Project

EV Companion is a Python application designed to manage basic electric vehicle information, user details, and trip history.

The project was built while learning Python programming, file handling, database concepts, and modular application development.

## ✨ Features

* 👤 EV profile setup
* 🔐 User login flow
* 🚗 Manage EV details
* 🧭 Store trip information
* 📋 View trip history
* 💾 File handling for data storage
* 🗄️ SQLite database integration
* 🧩 Modular Python code structure

## 🛠️ Technologies Used

* Python
* SQLite
* File Handling
* Object-Oriented Programming
* Git
* GitHub
